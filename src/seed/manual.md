# 浮光 · AI 世界观编辑器 — 使用说明

> 版本：v2.0.0 ｜ 架构：Electron 31 + React 18 + TipTap + Vite，设计语言严格遵循 **Fluent Design System**（界面无 emoji 装饰）。
> 本说明覆盖当前版本的全部功能与模块，帮助你快速上手并充分使用每一个能力。

---

## 一、这是什么

浮光是一款面向**虚构世界构建者**的桌面编辑器：用结构化的「实体 + 关系 + 时间线 + 文档」搭好你的世界观，再借助 AI 检索/工具调用把设定真正用起来，最后用「可视化编辑器」把世界观数据一键变成可用产出物（卡片、图谱、海报等）。

核心特点：

- **全本地优先**：所有数据实时写入本地 `.world` 文件，无账号、无强制联网；AI 仅在你配置并调用时联网。
- **结构化世界观**：五类实体（角色 / 势力 / 地点 / 事件 / 规则）+ 关系 + 时间线，天然支撑宏大设定。
- **AI 原生**：约束模式让 AI 自动遵守你已建立的设定；语义检索弥补词法检索的不足；文章抽取 / 实体关联 / 多模态设卡把原料快速变成结构化数据。
- **产出导向**：可视化编辑器支持模板 + 风格 + 八源字段绑定，导出 PNG / PDF / SVG 与社交图，并可批量生成套系。
- **提案机制**：AI 生成的一切修改先进入「提案中心」，由你逐条确认后再落地，绝不偷偷改写你的世界。

## 二、首次启动与快速开始

1. **新建世界观**：点击左侧图标栏最上方的「世界观管理」，在弹出的窗口中：
   - 输入世界名称，选择模板：
     - **空白**：零文件、零时间轴。
     - **小说**：角色 / 场景 / 章节三文件夹 + 3 篇示例文档 + 主线时间。
     - **剧本**：角色 / 场次两文件夹 + 2 篇示例文档 + 剧本时间。
   - 点「＋ 新建」即可。
2. **开始页（StartPage）**：无打开文件时展示近期编辑列表与快捷操作；可在「设置 → 外观」中关闭「启动时显示开始页」。
3. **文件树（FileTree）**：左侧栏管理文章 / 可视化文件夹，新建、重命名、删除文档。点工具栏「展开文件树」图标可收起/展开。
4. **多标签页**：每个文档、实体、时间轴、模块都是独立标签页，支持**分屏**（同时看两个页面）。标签页状态自动持久化，崩溃/重启不丢。
5. **实时保存**：所有改动实时写入本地，**无需手动保存**；左侧栏底部为保存按钮（点击会有 ✓ 反馈）。退出时弹窗确认，提示数据已自动保存。

> 提示：第一次使用 AI 功能前，请先到「设置 → 大模型接入 (AI)」配置至少一个模型。

## 四、实体库（结构化世界观的基石）

打开方式：图标栏「实体库」按钮，或从文件树新建。

### 4.1 列表与筛选
- 顶部显示实体总数、关系连线数。
- 按类型筛选（角色 / 势力 / 地点 / 事件 / 规则），支持按名称或标签搜索。
- 每个实体卡片展示封面图、类型、名称、前 3 个字段、标签与关系数量（连线度）。

### 4.2 新建与编辑实体
- 点「＋ 新建实体」，选择类型并命名（可留空自动命名）。
- 实体编辑器包含以下分区：
  - **插图**：可添加多张插图，指定一张为封面（实体库卡片以封面作半透明背景）。
  - **结构化字段（M1）**：按类型模板预置字段，例如角色含身份/阵营/年龄/外貌/性格/动机/经历；阵营含性质/领袖/据点/信条/势力范围等。字段支持「实体引用」类型（下拉选择其他实体，如「阵营」字段可关联到势力/地点）。可随时「＋ 加字段」。
  - **自定义字段**：自由增删键值对，灵活补充模板未覆盖的信息。
  - **标签**：输入后回车添加，点击标签可删除（如：主角、反派）。
  - **备注**：自由文本。
  - **关系（M2）**：在此连线到其他实体，选择关系类型（归属 / 敌对 / 发生 / 因果 / 亲缘 / 自定义）并可加说明；点击关系中的实体名可跳转。亲缘/敌对为对称关系，建议双向都连，否则一致性检查会提示「对称关系缺失」。
  - **时间线节点**：为实体添加多个时间节点（年份 + 影响力 0–100 + 备注），表示转折、成长阶段等；可直接打开所属时间轴。
  - **评论（M7-3）**：对实体添加评论（如创作备注）。
  - **版本历史（M7-3）**：手动「保存当前为版本」生成快照，可随时回滚（仅名称/字段/标签/备注等核心内容）。
  - **AI 补全建议**：基于当前实体与世界观设定，让 AI 补全缺失字段、延展背景、指出潜在冲突（要点输出，可复制）。

### 4.3 AI 辅助导入
- **导入文章并抽取**：粘贴或上传 `.txt / .md` 正文，模型识别其中的实体与关系，预览后「加入提案队列」。抽取时回传当前世界的已有实体做去重（名称精确命中或模型判定为同一事物则跳过）。
- **实体关联**：粘贴包含名称的文本，选择匹配模式（精确 / 模糊 / 大模型），将文中名称关联到实体库——匹配上的作为别名、未匹配的作为新建候选，结果进入提案队列。

## 五、线索板（关系图）

打开方式：图标栏「线索板」按钮。基于 **SVG 力导向物理模拟**的实体关系图。

- **节点**：五类实体各有固定颜色（角色紫 / 势力红 / 地点蓝 / 事件橙 / 规则绿），大小默认 56px。
- **连线模式**：点「连线模式」→ 选关系类型 → 先点源实体再点目标实体即建立关系；点关系线上的标签可删除该关系。
- **筛选**：按节点类型、关系类型筛选；支持「名称正则」（如 `^林` 或 `守.*人`）。匹配搜索/正则的节点会被高亮（橙框）。
- **交互**：
  - 点击节点：打开实体详情。
  - 右键节点：自定义颜色 / 大小（小40·中56·大76）/ 形状（圆·方·菱）/ 删除实体。
  - `Ctrl + 滚轮`：以光标为中心缩放；按住**中键**拖动平移；「重置视图」回到 100%。
- **背景**：可设置本地图片作线索板背景，选填充方式（覆盖/适应/拉伸/平铺/居中）与缩放比例。
- **关系列表**（右侧）：列出全部关系，双击跳转源实体，可单条删除；支持「清空关系」。

## 六、一致性检查（M3 引擎）

打开方式：图标栏「一致性检查」按钮。在实体与关系之间自动校验设定冲突。

- **强冲突**：设定硬伤，必须修（如关系指向不存在的实体、循环归属等）。
- **弱提示**：默认开启，可在特定世界观需要时关闭（如某对称关系本就不适用）。
- 顶部统计强/弱问题数量；每条冲突显示规则名、说明，并可一键**跳转到相关实体**修正。
- 规则开关区列出所有规则（强规则固定开启不可关，弱规则可单独关）。

## 七、时间线

打开方式：从实体编辑器的时间线节点「打开时间轴」，或在文件树/标签页打开时间轴文档。

- 支持**多条时间轴**，可新增/切换；时间单位支持年份 / 月份 / 日期 / 自定义（自定义可设单位名与换算层级，如「1 轮回 = 12 纪元」）。
- **节点**：每个事件含名称、年份、影响力（决定圆点大小 8–24px）、备注、可选关联实体。
- **交互**：
  - `Ctrl + 滚轮`：以光标为中心整体缩放轴线。
  - **左键拖空白处**：平移。
  - **右键空白处**：弹出菜单，可「＋ 添加节点 / ＋ 添加时间轴 / 编辑 / 删除 / 关联实体」。
  - 点击节点查看详情；双击/菜单「打开关联实体」跳转。
- 自动避让堆叠：同年多节点上下分 lane 显示，避免重叠。

## 八、草稿箱

打开方式：文件树新建草稿，或世界数据中的草稿集合。

- 卡片式列表 + 富文本详情编辑；标题/内容**防抖 600ms 自动保存**（标题非「未命名」或内容非空时才存）。
- 富文本工具栏：加粗、斜体、删除线、H1/H2、列表、引用、代码块。
- **AI 操作**（需配置模型）：
  - **分析**：提取摘要、角色、地点、时间点。
  - **转文档**：把草稿要点创建为新文档。
  - **转事件**：从内容提取时间点，创建时间轴事件。

## 九、富文本文档编辑器

基于 TipTap 的所见即所得编辑器，支持：

- 基础：加粗 / 斜体 / 删除线 / 下划线、标题（H1–H3）、有序无序列表、引用、代码块、分割线、**表格**。
- 扩展能力：
  - **标注块（Callout）**：醒目提示框。
  - **评论（Comment）**：行内评论。
  - **脚注（Footnote）**。
  - **公式（Math）**：LaTeX 数学公式。
  - **高亮（Highlight）**：标记重点。
  - **图片（Image）**：插入并支持环绕排版。
  - **维基链接（WikiLink）**：用 `[[实体名]]` 关联实体，点击跳转。
  - **字号（FontSize）**、字体。
  - **斜杠命令（Slash / Suggestion）**：输入 `/` 唤起快捷插入。
  - **右键菜单**：把选中内容一键送入 AI 侧栏作为上下文。

## 十、AI 助手（右侧栏 · Copilot）

展开方式：图标栏「AI 侧栏」按钮，或 `Ctrl/Cmd + 唤出`（取决于快捷键）。

- **模型选择**：下拉切换已配置的模型（设置中管理）。
- **约束模式**（核心）：开启后，AI 会参考你已建立的设定并不与之矛盾。输入问题时自动检索相关实体作为约束注入；可逐条**忽略**不想参考的设定。
- **任务按钮**：续写（叙事正文）/ 灵感（发散点子）/ 考据（逻辑与设定校验）/ 自由对话——不同任务自动调整温度。
- **语义检索**：已配置嵌入模型时，近义或改写的提及也能命中相关设定（未配置则回退词法检索）。
- **引用上下文**：手动把文章/实体固定为 AI 的长期参考（与约束模式独立，始终生效）。
- **多模态**：可附多张图片发送（前端自动压缩；需模型为 `chat` 格式且支持视觉输入）。
- **思维链**：支持深度思考的模型可展开/收起「思考过程」。
- **引用追溯**：回答后列出本次引用的设定，点击跳转到对应实体。
- **持久化**：对话按当前世界落盘（`WorldData.chats`），切换世界自动保存/载入，关闭重开仍在。
- **终止 / 清空**：响应中可「停止」；可「清空」会话。

## 十一、设置

打开方式：图标栏「设置」按钮。

### 11.1 外观
- **主题**：浅色 / 深色 / 护眼 / 蓝调 / 跟随系统。
- **自定义主题色**：取色器 + 预设色板，应用到按钮/高亮/边线。
- **窗口效果**（桌面版）：无 / AERO / 亚克力 / 云母 毛玻璃；效果模式下可设**渐变配色**（深海/极光/暮光/余烬/霜雪/自定义）与**模糊强度**。
- **标题栏模式**：系统标题栏 / 自建标题栏（切换需重启）。
- **开始页开关**。

### 11.2 大模型接入 (AI)
- 支持多个 **OpenAI 兼容 API**（OpenAI / DeepSeek / LiteLLM / Ollama / LM Studio 等）。
- 新增/编辑模型：别名、API 端点、Key、模型名、**提示词格式**（chat / qwen / instruct / raw）、自定义系统提示词。
- **能力开关**（务必按模型真实能力勾选）：
  - 支持视觉输入
  - 输出含深度思考
  - **支持工具调用（已受过工具使用训练）**——勾选后，文章抽取/实体关联等功能会让模型按需检索世界观上下文（需模型原生支持 Function Calling，如 GPT-4o / DeepSeek / Qwen 等 chat 格式；本地小模型未训练请勿勾选，否则报错）
  - 支持联网搜索（可填参数名，如 `enable_search`）
- **计量与预算**：启用用量统计后，可设最大上下文窗口、输入/输出单价、费用上限、Token 上限（预算护栏）。
- 支持「测试连接」「拉取模型列表」（点选填充模型名）。
- **AI 用量中心**：查看各模型调用次数、Token、费用。

### 11.3 嵌入模型（语义检索）
- 配置一个 OpenAI 兼容嵌入模型（如 `text-embedding-3-small / bge-m3 / nomic-embed-text`），用于语义检索（近义/改写提及也能命中）。未配置时自动回退词法检索，不影响任何功能。
- 可填端点、Key、模型名、**向量维度**（可选）。
- **语义索引管理**（本区）：
  - 索引缓存了每个实体的向量，**重启应用无需重新生成**。
  - **立即索引 / 更新**：手动增量重建（只重算变化的实体）。
  - **清除索引**：删除当前世界的向量索引文件。
  - **自动索引策略**：仅手动 / 实体变更自动（防抖 2s）/ 保存时自动（防抖 5s）。
  - 统计：已索引实体数、最近更新时间、索引体积（KB）。

### 11.4 导出 / 导入
- **导出为 JSON**：当前世界观完整备份。
- **导出为 Markdown**：便于阅读/迁移。
- **从 JSON 导入**：选择有效世界观 JSON，自动创建新世界并载入（同名则提示）。

### 11.5 存储位置
- 显示数据目录，可「打开文件夹」「创建/校验」新路径（切换后自动迁移历史数据）。

### 11.6 快捷键
- 列出全部可自定义动作（保存、切换侧栏、打开模块、搜索、新建实体/文档、撤销/重做等）。点按钮后按组合键录制，冲突会提示；支持「恢复默认」。

## 十二、可视化编辑器（MaterialForge · 把数据变产出物）

打开方式：图标栏「可视化编辑器」按钮。三栏布局：左=模板+风格，中=实时预览，右=属性与产出。

### 12.1 模板与风格
- **模板**：内置模板（如角色卡、势力卡等）+「我的模板」（用户自建/导入）。
- **风格（StyleToken）**：控制配色、字体、纹理、画幅等。可「新建风格」并编辑，内置风格不可删。
- **八源字段绑定**：模板 Block 可从八种来源取值——`entity`（实体字段）/ `customField`（自定义字段别名）/ `field`（通用字段）/ `world`（世界名等）/ `style`（风格令牌）/ `image`（插图/头像）/ `static`（常量）/ `relation`（关系）/ `ai`（AI 生成）。用 `{entity:name}`、`{customField:key}`、`{world:xxx}` 等插值，并支持 `showIf` 条件渲染。
- **输出尺寸默认对应风格**：输出尺寸默认跟随当前风格的「画幅」；模板锁定画幅时优先于风格。在风格编辑器改画幅后，回到可视化编辑器会立即跟随（右栏有「默认跟随当前风格」提示）。

### 12.2 属性与头像
- **预览实体**：选择要渲染的主体实体。
- **头像来源**三模式：
  - 实体插图（取实体首图/封面）
  - 用户上传（本地图片）
  - **AI 生成**（OpenAI 兼容文生图；再次生成以现有 AI 头像为参考图 refImage 锁，保持同角色一致）
- **AI 增强**总开关。
- **预览缩放**滑块。

### 12.3 AI 文案与字段
- **AI 生成文案并写入字段**：生成背景简介写入实体的 `materialFields[key]`（customField 按 key 映射），模板用 `{customField:key}` 展示。可选语气（正式/轻松/冷峻/荒诞）。
- **AI 字段补全**：扫描模板中 `source:'ai'` 的字段逐个生成，结果进入「提案中心」待采纳后才写入实体。

### 12.4 产出与导出
- **导出当前预览图**（所见即所得，直接截预览区）。
- **导出 PNG / PDF**（印刷级，离屏渲染保证与预览一致）。
- **复制图片**（社交分享，写入剪贴板）。
- **导出 SVG**（矢量，纯渲染进程生成）。
- **批量生成套系**：对多个实体套用同一模板+风格批量出图，并收进画廊。
- **套系 / 变量矩阵**：多变量组合生成。
- **视觉一致性校验**：检查产出在配色/字体/版式上是否一致。
- **物料画廊**：查看/管理已导出物料。
- **市场 / 库**：模板与风格的本地市场（纯本地、零在线依赖，`.fugu*` 文件导入导出）。
- **模板编辑器**：可视化编辑/新建模板（Block 树）。
- **NL 建模板**：用自然语言描述生成模板（模型按 Block schema 输出，预览后导入）。
- **多模态设卡**：上传文字+图片，由模型填充字段并生成头像，渲染后入提案队列。

## 十三、提案中心

打开方式：图标栏「提案中心」灯泡图标（有待处理项时显示角标数字）。

- 所有 AI 生成的实体、关系、字段、模板先进入此处，**按来源分组**（文章抽取 / 物料 / 实体关联 / 模板生成 / 对话 / 手动）。
- 每条显示摘要与操作类型；可**逐条采纳 / 拒绝**，或「全部采纳」。
- 已处理项可「清空已处理」。采纳时才真正写入世界观，拒绝则丢弃——你始终掌控最终数据。

## 十四、协作与分享

打开方式：图标栏「协作与分享」按钮。纯本地、无后端版本（实时多人协同需后端账号体系，本构建以「合并导入」作本地替代）。

1. **选择要分享的设定**：按类型勾选实体；可「仅分享选定字段」（脱敏，未勾字段不导出）。
2. **分享选项**：分享标题、有效期（可选）、说明。
3. **导出**：
   - **分享快照 (JSON)**：范围可控的快照，他人可合并导入。
   - **独立查看器 (HTML)**：双击即可在浏览器查看，接收方无需安装软件。
4. **合并导入**：选择他人分享快照或世界备份 JSON，同名/同 ID 实体触发冲突，逐条选择「保留本地 / 用导入覆盖 / 重命名导入」，再一键合并。

## 十五、AI 辅助功能汇总

| 功能 | 入口 | 说明 |
|---|---|---|
| 文章抽取实体 | 实体库 → 导入文章并抽取 | 粘贴/上传正文，模型识别实体+关系，去重后入提案 |
| 实体关联 | 实体库 → 实体关联 | 文本名称→实体库，精确/模糊/大模型三模式，结果入提案 |
| 约束模式 + 语义检索 | AI 侧栏 | AI 自动遵守设定；嵌入模型支持近义命中 |
| 多模态设卡 | 可视化编辑器 → 多模态设卡 | 文字+图片填充字段+生成头像，入提案 |
| AI 字段补全 | 可视化编辑器 | 扫描模板 `source:ai` 字段生成，入提案 |
| NL 建模板 | 可视化编辑器 → NL 建模板 | 自然语言生成模板 |
| 草稿 AI | 草稿箱 | 分析 / 转文档 / 转事件 |
| 实体 AI 补全 | 实体编辑器 | 补全字段、延展背景、指冲突 |

> 关于「工具调用」：在「设置 → 大模型接入」勾选某模型的「支持工具调用（已受过工具使用训练）」后，文章抽取/实体关联等流程会让模型按需检索世界观上下文，更适配宏大世界观；请仅对原生支持 Function Calling 的模型勾选。

## 十七、存储、备份与迁移

- 数据实时写入本地 `.world` 文件（实体、关系、时间线、文档、草稿、风格、用户模板、提案、对话历史等）。
- **备份**：设置 → 导出 / 导入 → 导出为 JSON（完整备份）；或复制存储目录全部文件。
- **迁移**：设置 → 存储位置 → 创建/校验新路径，旧数据自动迁移。
- **多世界**：世界观管理可新建多个世界，各自独立存储；切换世界自动保存/载入当前世界对话。

## 十八、常见问题

- **AI 功能提示「未配置模型」**：到「设置 → 大模型接入 (AI)」新增模型并「设为当前」。
- **语义检索不生效**：需在「设置 → 嵌入模型」单独配置嵌入模型；未配置时自动回退词法检索。
- **导出与预览不一致**：离屏渲染与实时预览共用同一外壳与模板渲染，确保一致；若仍异常请确认模板 `pageOverride` 与风格 `layout.page`。
- **关系图卡顿**：大数据量时可关闭非必要类型/关系筛选，或缩小可见范围。
- **标题栏切换后无变化**：需重启应用生效（设置中有提示）。
