## 0. 已确认的产品决策（对应功能表单 §13）

| # | 问题 | 决策 | 对设计的影响 |
|---|---|---|---|
| 1 | 生成方式 | **混合模式**；每张物料可单独开关"是否使用 AI"；设置页提供 AI 接入端口 | 新增预览/导出层的 `useAI` 开关；设置页新增 AI 接入区；ai 抽象层可配 endpoint |
| 2 | 头像来源 | **三模式均支持**：① 浮光实体库角色插图 ② 用户上传 ③ AI 生成 | 物料内头像选择器三选一；`AssetMeta` 区分来源；AI 生成用 refImage 锁保证同角色一致 |
| 3 | 风格定义 | 手动调色板/字体/纹理为主；允许在 **Copilot** 用自然语言调整（如"主色改暗红"） | `StyleEditor` 手动控件；P2 增加 Copilot intent→改 `StyleToken`；StyleToken 必须可被程序化修改 |
| 4 | 输出用途 | 社交分享 + 印刷实体等 | 导出预设：社交长图 1080×1920、方图 1080×1080、A4 高分辨率 PDF、自定义 |
| 5 | 集成深度 | **内置新模块，替换原有"可视化编辑器"(CardEditor/visual)** | 复用 `visual` 模块槽位（`App.tsx:103`）渲染 `MaterialForgeView`；旧 visual 画布数据见问题 1 |
| 6 | 世界观泛化 | 覆盖非机构类世界观；模板与字段通用 | 实体增加 `customFields` 通用键值；模板 `applicableStyles:['*']` 且字段通用，机构风仅作演示预设 |

### 0.1 决策细化（原 §7 三问，已确认）

| 原问 | 决策 | 对工单的影响 |
|---|---|---|
| 旧 Visual 画布数据如何处理 | **直接下线并删除旧数据**（不再迁移、不再保留 CardEditor） | **P0-2 升级为"完整移除 Visual 模块"**：删除 `CardEditor.tsx` 及其引用；从 `types.ts` 移除 `VisualDoc`/`CanvasPreset`/`CardData`；从 `worldStore.ts` 移除 `visualDocs`/`visualPages` 及 `addVisualDoc`/`updateVisualDoc`/`deleteVisualDoc`/`renameVisualDoc`/`moveVisualToFolder`/`addVisualPage`/`deleteVisualPage`；`FileTree.tsx` 移除"新建可视化"按钮与 visual 拖拽/右键逻辑；`TabBar.tsx` 移除 visual 搜索；`icons.tsx` 的 `IconVisual` 改为 `IconMaterials`。⚠️ 删除属不可逆操作，实施前需在设置/构建期给出一次性确认或导出兜底 |
| AI 接入按什么协议 | **OpenAI 兼容协议**，头像生成可接入市面主流文生图模型 | `ai.ts` 抽象层实现 OpenAI 兼容 `POST {base_url}/images/generations`（prompt + 可选参考图 img2img）；设置页存 `base_url/api_key/model`；P2 头像生成走此通道，refImage 作为参考图传入（不支持 img2img 的 provider 退化为强 prompt 嵌设） |
| 实体通用字段按 key 还是 label 引用 | **按 key 映射** | `FieldBinding.source:'customField'` 时 `path` 直接取 `customFields` 的 `key`（如 `entity.customFields['编号']`）；模板字段声明与 `bindings.resolve` 统一按 key |

## 2. P0 详细工单（文件级）

### P0-1 类型与状态层
**目标**：定义模块全部数据结构，建立状态容器。
**涉及文件**：
- 新建 `src/features/materials/types.ts`
  - `StyleToken`（见开发文档 §4.1，新增 `id` 绑定 `worldviewId`）
  - `Template` / `Block` / `FieldBinding`（见开发文档 §4.2，FieldBinding.source 增加 `'customField'`）
  - `AssetMeta`（kind 增加 `portrait-entity`/`portrait-upload`/`portrait-ai` 区分来源）
  - `RenderJob`（entityId, templateId, styleId, useAI, portraitMode, scale, size, status）
  - `MaterialManifest`（记录已生成物料来源）
- 新建 `src/features/materials/store.ts`（Zustand）
  - state: `styles`, `activeStyleId`, `templates`, `activeTemplateId`, `assets`,
    `preview:{entityId,templateId,styleId,useAI,portraitMode,overrides}`, `renderQueue:RenderJob[]`
  - actions: `setActiveStyle/setActiveTemplate/setPreview/pushJob/updateJob/setAsset`
- 修改 `src/types.ts`：扩展 `Entity` 增加 `portrait?`, `spectrumColor?`, `signature?`, `customFields?: {key:string; value:string; type:'text'|'number'|'image'}[]`（不破坏存量）
- 修改 `src/store/worldStore.ts`：`WorldData` 增加 `styles: StyleToken[]`、`materialManifest?: MaterialManifest`
**依赖**：`zustand`(已有)、`uuid`(新增依赖)、`zod`(新增依赖，用于模板/风格 JSON 校验)
**验收**：`npm run build`（tsc --noEmit）通过；`materialStore` 可被其他模块 import；实体扩展字段向后兼容。

### P0-2 入口与三栏主界面（替换 Visual 模块）
**目标**：用 MaterialForge 替换原 CardEditor 入口，搭建三栏骨架。
**涉及文件**：
- 修改 `src/App.tsx:103`：`if (tab.kind === 'visual') return <MaterialForgeView key={...} />`（移除 `CardEditor` 作为入口；`visual` tab kind 保留以最小化类型改动）
- 修改 `src/components/Toolbar.tsx`：原"可视化"模块按钮改为"物料生成"，点击打开 `visual` 模块（label 改，逻辑复用）
- 修改 `src/components/icons.tsx`：新增 `IconMaterials`（Fluent 24×24 SVG，stroke:currentColor）；保留 `IconVisual` 兼容
- 新建 `src/features/materials/MaterialForgeView.tsx`：三栏布局
  - 左：实体选择（接 `EntityLibrary` 数据）+ 模板选择（`StyleList`/`TemplateList` 占位）
  - 中：预览区（`TemplateRenderer` 占位，P0-5 接入）
  - 右：风格选择 + 导出面板（P0-7 接入）+ "使用 AI"开关 + 头像来源三选一
  - 套用 Fluent 令牌（`--accent`/`--bg-elev`/`--shadow`，参考 `DESIGN_FLUENT.md` §4）
**依赖**：P0-1（store/types）
**验收**：点工具栏进入模块，三栏渲染；空态（无实体/无风格）有引导文案；不报错。

### P0-3 风格编辑（手动）
**目标**：用户可手动定义/编辑美术风格令牌。
**涉及文件**：
- 新建 `src/features/materials/StyleSystem/StyleList.tsx`：列出当前世界观风格，新建/选中/删除
- 新建 `src/features/materials/StyleSystem/StyleEditor.tsx`：
  - 配色：取色器（primary/secondary/bg/danger/accent + `forcedMono` 开关）
  - 字体：下拉（接 `font-list` 探测系统字体 + 用户导入项），title/body/handwriting/mono
  - 纹理：type 选择 + `noise`/`aging` 滑块
  - 版式：`margin`/`columns`/表格线型/页眉页脚格式输入
  - 语气词典：`toneLexicon` 键值编辑表
  - 写入 `materialStore.setActiveStyle` → 持久化到 `worldStore.styles`
**依赖**：P0-1
**验收**：改主色 → 预览区 CSS 变量实时变化（P0-5 后可见版式随动）；风格随世界观存档。

### P0-4 三个通用模板
**目标**：交付 Staff File / ID Card / Menu 三模板，字段通用。
**涉及文件**：
- 新建 `src/features/materials/TemplateEngine/templates/staffFile.ts`
- 新建 `src/features/materials/TemplateEngine/templates/idCard.ts`
- 新建 `src/features/materials/TemplateEngine/templates/menu.ts`
- 每个模板：`kind`、画布 `width/height`、`root: Block[]`、`fields: FieldBinding[]`
  - 字段引用 `entity.name`/`entity.customFields['编号']`/`entity.portrait` 等通用路径
  - `applicableStyles: ['*']`（通用引擎，机构风仅作演示数据）
  - `cond` 示例：`entity.customFields['义体'] === 'true'` 才显示改造栏
**依赖**：P0-1（类型）
**验收**：三模板可被 `TemplateList` 加载；`fields` 声明完整、可被 `bindings.resolve` 消费。

### P0-5 渲染与字段绑定
**目标**：把数据填进模板并渲染成预览。
**涉及文件**：
- 新建 `src/features/materials/TemplateEngine/bindings.ts`：
  - `resolve(entity, style, template, portraitMode): ResolvedBlock`
  - 取值：`entity`/`customField`/`style`/`literal`；`source:'ai'` 时返回占位 + 标记待 AI（P2 补全）
  - `formatter`：`upper`/`abbr`/`random_id`/`none`
  - `cond` 简单表达式求值
- 新建 `src/features/materials/TemplateEngine/TemplateRenderer.tsx`：
  - 递归渲染 `Block`：text/image/table/divider/icon/group/repeat
  - `image` 按 `portraitMode`：① `entity`→`entity.portrait` ② `upload`→`overrides.portraitUpload` ③ `ai`→`asset.portrait-ai`（P2 生成）
  - 根节点注入 style CSS 变量（`--mg-primary` 等），应用字体/纹理
**依赖**：P0-3（style 令牌）、P0-4（模板）
**验收**：示例实体 + 风格 → 预览正确显示姓名/编号/头像框/三栏；改风格令牌版式随动。

### P0-6 渲染管线 + 主进程 IPC（PNG 导出）
**目标**：把预览 HTML 离屏捕获为高质量 PNG。
**涉及文件**：
- 新建 `src/features/materials/Render/previewToHtml.ts`：`resolved → 自包含 HTML 字符串`（内联 CSS 变量、`@font-face`、纹理 `dataURI`、图标内联 SVG）
- 新建 `src/features/materials/Render/exportImage.ts`：`ipcRenderer.invoke('material:capture', { html, scale, clip })` → 返回 PNG DataURL/Buffer
- 修改 `electron-main.cjs`：新增 `ipcMain.handle('material:capture')`
  - 创建离屏 `BrowserWindow`（背景透明/白）
  - `loadURL('data:text/html,...')` 或 `setContent(html)`
  - 等待 `document.fonts.ready` 后 `webContents.capturePage(rect)`（`deviceScaleFactor = scale` 实现 2x/4x）
  - 返回 PNG
**依赖**：P0-5（`previewToHtml` 输入）
**验收**：导出 1x/2x PNG 与预览无肉眼差异；超大图不崩；字体正确。

### P0-7 预览 + 导出 UI（多尺寸/AI 开关/头像三选一）
**目标**：闭环打通，产出首张可用物料。
**涉及文件**：
- 扩展 `src/features/materials/MaterialForgeView.tsx`：
  - 中栏接 `TemplateRenderer` 实时预览
  - 右栏导出面板（`Render/exportPanel.tsx` 或内联）：
    - 格式：PNG / PDF（PDF 在 P1 启用，先置灰）
    - 倍率：1x / 2x / 4x
    - 尺寸预设：社交长图 1080×1920、方图 1080×1080、自定义 W×H
    - "使用 AI"开关（写入 `preview.useAI`）
    - 头像来源：实体插图 / 上传 / AI（写入 `preview.portraitMode`）
  - 导出按钮 → `exportImage` → 写 `manifest.json` + 资产引用 +1
**依赖**：P0-5、P0-6
**验收**：选实体+模板+风格 → 预览 → 导出 PNG，全流程 ≤ 30s，字段填充正确。
