# 浮光 · 视觉物料生成器（Visual Material Generator）功能表单

> 版本：草案 v0.1 ｜ 2026-07-20
> 定位：在浮光世界观编辑器内新增一个模块，把"实体库里的角色/组织数据 + 用户选定的美术风格"稳定地渲染成**世界观内的视觉物料**（员工档案、ID 卡、菜单、招募海报、技术蓝图、事故通报、监控截图等）。
> 关键约束：不局限于某一个世界观（如 PG309/HRI），必须能套用到**任何拥有美术风格的世界观**（奇幻公会、科幻舰队、校园社团、赛博企业、克苏鲁教团……）。

---

## 0. 一句话定义与价值

| 项 | 说明 |
|---|---|
| 输入 | ① 世界观/美术风格设定 ② 角色/组织/物品的结构化数据（来自浮空已有实体库） |
| 输出 | 一套风格统一、看起来"像该世界观真实存在的文件/海报/卡片"的视觉图片（PNG/PDF/SVG） |
| 核心难点 | **风格一致性** + **批量稳定产出** + **跨世界观可迁移** |
| 与现有浮光关系 | 复用 Entity / WorldContext / Consistency / Copilot / Share 五大模块，新增 Style System、Template Engine、Render Pipeline、Export 四块 |

---

## 1. 总体架构（模块关系图）

```
[ 实体库 Entity ] ──角色/组织数据──┐
                                    ├─► [ 模板引擎 Template Engine ] ──► [ 渲染管线 Render Pipeline ] ──► [ 导出 Export ]
[ 世界上下文 WorldContext ] ─风格设定┤        （绑定字段→版式槽位）          （HTML/CSS + AI图像 + 字体/纹理）   （PNG/PDF/SVG）
                                    │                                                      │
[ AI/Copilot ] ──文案/头像/Logo生成────────────────────────────────────────┤
                                    │
[ 一致性检查 Consistency ] ◄──风格令牌&命名&时间线校验──────────────────────┘
```

新增四大子系统：
- **Style System（美术风格系统）**：把"风格"建模成可复用、可校验的数据。
- **Template Engine（模板引擎）**：把数据填进版式。
- **Render Pipeline（渲染管线）**：把模板变成图片。
- **Export（导出）**：多格式、多尺寸、批量。

---

## 2. 美术风格系统（Style System）—— 最关键的一层

因为要支持"任何世界观"，"风格"必须被拆成**可参数化、可反推、可校验**的要素，而不是写死一张图。

### 2.1 风格预设库（Style Presets）
- 内置可复用预设：`机构档案/黑白临床`、`赛博朋克霓虹`、`奇幻羊皮卷`、`校园手账`、`像素 RPG`、`像素等宽终端`、`复古军事公文`、`可爱贴纸风` 等。
- 每个预设是一组"风格令牌（Style Tokens）"的打包。

### 2.2 风格令牌要素（必须可定义）
| 要素 | 内容 | 示例（HRI 风） |
|---|---|---|
| 色彩令牌 | 主色/辅色/底色/危险色/强调色 + 是否强制黑白 | 黑白 + 深蓝点缀 |
| 字体组 | 标题字体、正文字体、手写体、等宽体（可绑定本地字体） | Segoe UI / 手写体 / 等宽 |
| 纸张/材质 | 纯白、做旧米黄、扫描噪点、复印退化、屏幕 UI、羊皮纸 | 低分辨率扫描 + 轻微噪点 |
| 图标符号库 | 该世界观专属图标（骷髅、地球裂解、条形码、阵营纹章） | 骷髅 + 地球裂解 |
| Logo/徽记 | 机构/阵营主标识（矢量，可反色/缩放） | HRI 地球裂解标 |
| 签名样式 | 个人签名/印章的生成规则 | 手写体 + 边框印章 |
| 版式网格 | 安全边距、栏数、表格线型、页眉页脚格式 | 公文三线表 + 页眉编号 |
| 装饰母题 | 角标、分隔线、水印、边框花纹 | 角标骷髅 + 编号水印 |
| **语气词典（Tone Lexicon）** | 该世界观的措辞/黑话/自称，供 AI 写文案时用 | "实验体""永久收容""福利"反讽 |

### 2.3 风格自定义
- 手动编辑所有令牌（色板取色器、字体下拉、纹理上传）。
- **参考图反推**：上传 1–N 张参考图 → AI 提取配色、字体气质、纹理、图标风格 → 生成初始风格令牌，用户再微调。（对应 AI 辅助 8.4）

### 2.4 风格 × 世界观绑定
- 一个世界观可绑定一个主风格 + 多个子风格（如"总部公文风""前线作战风"）。
- 切换世界观时，风格自动随附，保证整套物料同源。

### 2.5 风格导入/导出/共享
- 风格包 `.fuguestyle`（含令牌 JSON + 字体/纹理/图标资源）。
- 模板市场可发布/订阅风格包。

## 3. 角色/实体数据模型（Character Data Model）

复用浮光实体库，但**物料生成需要更结构化的字段**。建议在实体类型中扩展"可可视化字段"。

### 3.1 角色字段分组
| 分组 | 字段 | 是否必填 | 用途 |
|---|---|---|---|
| 基础身份 | 姓名/代号、种族、性别、年龄/诞辰、编号 | 是 | 填姓名栏、编号栏 |
| 视觉特征 | 主题色（光谱条）、立绘/头像图、剪影 | 头像可选 | 头像框、光谱条 |
| 机构归属 | 所属组织、部门、职级、职位代号 | 视模板 | ID 卡 / 档案页眉 |
| 档案栏 | CV、健康状况、工作小结、备注/潜文本 | 可选 | Staff File 三栏 |
| 签名 | 手写签名图 / 自动生成签名 | 可选 | 档案/合同落款 |
| 关系网 | 与谁同组织/敌对/上下级 | 可选 | 关系图、联合档案 |
| 状态变体 | 不同时间线/改造阶段的版本 | 可选 | 变量矩阵生成 |

### 3.2 字段 → 槽位映射（Field→Slot Mapping）
- 模板里用 `{{entity.name}}`、`{{entity.spectrum_color}}` 等占位符。
- 提供"字段映射面板"：把实体字段拖到模板槽位；未填字段可设**兜底值/自动生成**。
- 支持**条件渲染**：如 `cyborg == true` 才显示"义肢集成度"栏。

## 4. 物料模板引擎（Template Engine）

### 4.1 物料类型（模板库）
内置与 PG309 物料对应的基础类型，且可泛化：
- **人事类**：Staff File（员工档案）、ID Card（证件）、Recruitment Poster（招募海报）、Badge（徽章）
- **情报类**：Dossier（卷宗）、Incident Report（事故通报）、Interrogation（审讯记录）
- **日常类**：Menu（今日菜单）、Notice（公告）、Mail（内部邮件）、Schedule（排班表）
- **技术类**：Blueprint（装备蓝图）、Map（功能区示意图）、Spec Sheet（规格表）
- **叙事类**：Timeline Card（时间线卡）、Character Sheet（人物卡）、Faction Sheet（阵营卡）
- **自定义**：用户从空白或复制现有模板新建

### 4.2 模板结构（数据驱动）
- 模板 = **JSON Schema**：版式（网格/组件树）+ 槽位绑定 + 条件块 + 可重复区块（如"技能列表"循环）。
- 用声明式描述，而非写死像素，便于换风格、换数据。
- 支持**嵌套模板**：如一张海报里嵌一个 ID 卡组件。

### 4.3 模板变量与函数
- 文本变换：`大写/缩写/编号格式化`。
- 随机/生成器：`{{random_id("ANA-###")}}`、`{{lorem(40)}}` 用于填充虚构细节。
- 引用其他实体：`{{relation.target.name}}`。

### 4.4 模板编辑器
- **可视化编辑**：拖拽组件（文本框/图片框/表格/分割线/图标），绑定字段，设置条件。
- **代码编辑**：高级用户直接改模板 JSON/HTML。
- 实时预览：改动即时显示在右侧。

### 4.5 模板市场
- 发布/订阅/收藏模板；模板可标注"适用风格"（如"仅赛博公文风"或"通用"）。

## 5. 生成与渲染管线（Render Pipeline）

### 5.1 数据→模板绑定
- 选实体 + 选模板 + 选风格 → 自动填充，未填字段触发兜底/AI 补全。

### 5.2 HTML/CSS 渲染（所见即所得）
- 模板先渲染成标准 HTML/CSS（基于风格令牌生成 CSS 变量）。
- 优点：**稳定、可控、零 API 成本、可批量**，保证同一角色每次产出一致。

### 5.3 AI 图像生成与合成
- **头像/立绘**：用户上传或用 AI 生成，生成时带"参考图 + 风格令牌 + 负向提示"以保证同风格。
- **Logo/图标/场景插画**：AI 生成后存入资产库，后续复用以保一致。
- **合成**：AI 图作为图层嵌入 HTML 版式（头像框、背景水印、角落插画）。

### 5.4 字体与本地字体管理
- 接入系统字体（font-list 已支持）+ 用户导入字体（.ttf/.otf）。
- 字体缺失时按风格令牌回退，避免渲染崩坏。

### 5.5 导出
- 格式：**PNG（多倍率 1x/2x/4x）、PDF（印刷）、SVG（矢量再编辑）**。
- 尺寸：按平台预设（社交长图 1080×1920、帖子方图、A4 印刷）或自定义。
- 批量导出为压缩包，保留命名规则。

### 5.6 预览与微调
- 左右对照：左模板/数据，右成品。
- 支持"局部重生成"（只换头像、只改某栏文案）。

## 6. 一致性控制（Consistency）

复用浮光已有的 Consistency 模块，扩展视觉维度：

### 6.1 视觉令牌校验
- 同一世界观下，所有物料的主色/字体/Logo/页眉格式不得漂移。
- 风格令牌被改时，提示"将影响 N 张已生成物料"。

### 6.2 角色跨物料一致性
- 同一角色在不同文件用**同一头像、签名、编号、光谱色**（引用资产库而非重复生成）。
- 角色改名/换头像时，提供"全局更新引用"选项。

### 6.3 命名/编号/时间线一致性
- 接入现有 consistency：编号不重复、时间线不矛盾、组织名拼写统一。

### 6.4 风格冲突告警
- 若用户给"奇幻羊皮卷"风套了"赛博霓虹"模板，给出冲突提示与一键适配建议。

## 7. 批量产出与自动化（Batch & Automation）

### 7.1 批量生成
- 在实体库勾选 N 个角色 → 套同一模板+风格 → 一次产出 N 张。

### 7.2 套系生成（Kit Generation）
- 一键产出"某世界观完整物料包"：员工档案×全员 + ID 卡×全员 + 菜单 + 招募海报 + 蓝图 + 公告。

### 7.3 变量矩阵
- 同一角色 × 多状态（如"改造前/后""不同时间线"）→ 矩阵式批量出图。

### 7.4 队列与进度
- 大批量进渲染队列，显示进度、可暂停/重试失败项。

### 7.5 批量导出
- 整包 PNG/PDF + 一份 `manifest.json`（记录每张图的实体/模板/风格来源，便于回溯）。

---

## 8. AI 辅助

### 8.1 文案生成
- 按风格"语气词典"写档案/菜单/公告，避免出戏（如 HRI 的黑话反讽语气）。

### 8.2 头像/立绘生成
- 带参考图 + 风格令牌 + 角色特征 → 生成；支持"保持同一角色多姿势一致"（seed/参考图锁定）。

### 8.3 Logo/图标生成
- 从风格令牌生成阵营徽记、图标集；可迭代微调。

### 8.4 风格迁移（参考图反推令牌）
- 见 2.3。

### 8.5 自动补全缺失字段
- 角色字段空缺时，AI 按世界观合理补全（并标记"AI 生成，待审核"）。

---

## 9. 资产与素材管理（Assets）

### 9.1 资源库
- 字体库、纹理库（纸张/噪点/羊皮）、图标库、边框/印章库、背景图库。

### 9.2 角色资产
- 头像/立绘/签名/光谱条，按实体 ID 归档，跨物料引用。

### 9.3 引用与去重
- 显示某资产被多少物料引用；删除前告警。

---

## 10. 协作 / 分享 / 发布

- 复用浮光 Share 模块：导出包、分享链接、画廊视图。
- **水印/署名**：可选嵌入作者署名、世界观名、生成工具标识。
- **画廊（Gallery）**：世界观内物料墙，可拖拽排序、分组。

## 11. 工程与扩展性

| 项 | 说明 |
|---|---|
| 本地优先 | 排版渲染本地完成；AI 为可选增强（离线也能出基础物料） |
| 插件/模板 SDK | 第三方可发布风格包/模板（`.fuguestyle`/`.fugutemplate`） |
| 脚本 API | 高级用户用脚本批量生成（`generate(worldview, entities, template)`） |
| 性能 | 大批量用离屏渲染 + 队列，避免卡 UI |
| 可访问性 | 沿用 Fluent 设计令牌与 WCAG AA（焦点框、对比度） |
| 数据格式 | 风格/模板/资产均为开放 JSON，便于备份与版本管理 |

## 12. 最小可行版本（MVP）建议

按"先跑通核心闭环"原则，建议 v1 优先级：

1. **P0 风格令牌 + 3 个基础模板**（Staff File / ID Card / Menu）+ HTML/CSS 渲染 + PNG 导出。
2. **P0 实体字段扩展**：让角色数据能填进模板槽位。
3. **P1 批量生成**：勾选多角色一次出图。
4. **P1 一致性校验**：角色头像/编号跨图一致。
5. **P2 AI 头像/文案生成**（可选增强）。
6. **P2 模板市场 + 风格反推**。
7. **P3 套系生成 / 变量矩阵 / 高级模板编辑器**。

## 13. 待向你确认的关键问题（影响范围）

1. **生成方式偏好**：纯本地排版引擎（稳定/零成本/可控）？还是重度依赖 AI 图像（惊艳但不可控、有 API 成本）？还是混合（HTML 版式 + AI 只做头像/Logo）？—— 我倾向混合，PG309 这类物料其实 HTML/CSS 就能高质量复刻。
2. **角色头像来源**：用户自己上传/已有立绘，还是要 AI 现场生成？两者都要支持吗？
3. **风格定义方式**：用户手动调色板/字体/纹理，还是上传参考图让 AI 反推令牌？
4. **输出用途**：社交分享（长图/方图）、印刷实体（A4/高分辨率 PDF）、还是纯存档？决定导出规格。
5. **集成深度**：作为浮光内新模块（复用现有实体/一致性/AI），还是独立工具？
6. **世界观泛化度**：是否要覆盖"非机构类"世界观（奇幻公会、校园、舰队）？模板与字段是否需要更通用？
